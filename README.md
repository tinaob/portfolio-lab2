# Clementina's Portfolio (Lab 2: Interactive Portfolio Enhancements)

Course: DA558A HT26

## Target grade

Grade 5

## Features

I completed Lab 2 by enhancing my portfolio with interactive JavaScript features, including a validated feedback form, a data-driven skills showcase with filtering and sorting, and an accessibility panel for adjusting text size and contrast. I also worked with keyboard accessibility, persistent display settings, and reduced-motion preferences. The display settings are saved in the browser’s local storage, so when a visitor returns to the site or reloads the page, their chosen text size and contrast settings are restored automatically. This lab strengthened my understanding of JavaScript, DOM manipulation, event handling, responsive design, and accessible user interfaces.

- [x] Feedback form with validation (Grade 3)
- [x] Skills cards with filter and sort (Grade 4)
- [x] Display panel with text size and contrast settings (Grade 5)

## How to run

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose Open with Live Server, or just open `index.html` in a browser.

No installation is needed. The project uses plain HTML, CSS and JavaScript.
