Features will be added here as I build them:

## How to run

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose Open with Live Server, or just open `index.html` in a browser.

No installation is needed. The project uses plain HTML, CSS and JavaScript.
